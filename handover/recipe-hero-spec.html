Recipe Hero

The dark split hero at the top of a recipe detail page: a content panel (eyebrow, title, star rating, tags, author) beside a full-bleed photo panel with a favourite toggle. Same skeleton as Training Hero, and now documented with the same optional video treatment.

Anatomy & Rules

Two children — .ufs-recipe-hero__panel (fixed 40% width) and .ufs-recipe-hero__media (flex:1, fills the rest) — sitting side by side against a squid-ink background. Desktop only; the mobile breakpoint stacks them full-width, photo on top (see Mobile Examples).

Variants

Video Variant

Recipe Hero can hold a video the same way Training Hero does: a dark scrim over the photo plus a centred play control, opening a video in the DS's shared lightbox. Structurally it's Training Hero's __trailer control ported wholesale — same overlay, same 102px play circle, same hover-zoom on the photo — under the __watch name instead, with the visible label changed to "Watch preparation" rather than "Watch trailer".

💡
Renamed __trailer → __watch deliberately, not just relabelled: a recipe doesn't have a "trailer", it has a steps walkthrough. The class name change is internal only — nothing about the markup shape, CSS values, or interaction changes from Training Hero's version.
Default — photo only

i18n & RTL

The layout is entirely flex/gap-based with no physical margins, so it mirrors under dir="rtl" with only one explicit override: the favourite button's corner position.

Favourite button[dir="rtl"] .ufs-recipe-hero__favright → left, both desktop and mobile values
Watch controlno override neededicon + label are centred and stacked (flex-direction:column) — direction-agnostic
Content panelno override neededgap-based flex column throughout — text-align follows the browser's own RTL default

Developer

Usage

Pure CSS + a shared JS mechanic — no per-instance JS of its own. The photo-only default needs nothing beyond the markup in Anatomy above.

⚠️
The video variant is documented here but not yet wired into template-recipe-detail.html's live recipe — that page still ships the photo-only default. Adopting it on a real recipe page means adding the .ufs-recipe-hero__overlay/__watch markup shown above, plus the shared lightbox markup/JS from teaser-spec.html#video if that page doesn't already include it (template-training-detail.html already does, since Training Hero uses the same mechanic).
