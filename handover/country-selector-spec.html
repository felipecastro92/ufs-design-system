Country Selector

Side-panel drawer asking the visitor to pick their country, shown automatically only in markets that need it. Logo, title, description, then a list of flag + country-name rows. Picking a row sends the visitor to that country's site.

Source
full-page-preview-v0.2.html

Overview

Full Component Preview

It uses the same .signin-panel / .signin-backdrop drawer shell as Sign-in, Newsletter, Filters and the Wholesaler Picker: a 420px panel sliding in from the right (from the left in RTL) over a dimmed, blurred backdrop. Only the body content is new: .ufs-country-list, one bordered .ufs-country-item row per country.

💡
On this page the drawer opens on click rather than on load, so it doesn't cover the docs while you read. In production it opens itself 1.5s after page load. See data-auto-open.

Structure

Anatomy

Header: the shared .signin-panel-hd with the UFS logo only (no close button). Body: .signin-panel-title (H5), .signin-panel-desc (Body/Small), then .ufs-country-list, a <ul> of links. Each .ufs-country-item holds a 40px bordered __flag tile and a __name. Unlike the Wholesaler Picker there is no search field, no price or caption lines, and no external-link icon.

Reference markup
One row shown; repeat the <li> for each country the market offers.

Behavior

Trigger & Auto-Open

The component only renders in markets that need an explicit country choice (e.g. one regional site serving the GCC countries). Whether a market gets it is a CMS/backend decision: markets that don't need it simply omit the markup. When present with data-auto-open, it opens itself 1.5 seconds after page load, the same delay as the Takeover Banner.

JS — open / close / auto-open
JS
function openCountryPanel() {
  document.getElementById('country-backdrop').classList.add('is-open');
  document.getElementById('country-panel').classList.add('is-open');
  document.body.style.overflow = 'hidden';
  document.getElementById('country-panel-body').scrollTop = 0;
}
function closeCountryPanel() {
  document.getElementById('country-backdrop').classList.remove('is-open');
  document.getElementById('country-panel').classList.remove('is-open');
  document.body.style.overflow = '';
  document.activeElement.blur();
}
// Auto-open once per full page load
(function () {
  var panel = document.getElementById('country-panel');
  if (!panel || !panel.hasAttribute('data-auto-open')) return;
  setTimeout(openCountryPanel, 1500);
})();
⚠️
Only one auto-opening drawer or dialog per page. If a market has both a Country Selector and a Takeover Banner marked data-auto-open, the Country Selector should win and the takeover should wait for a later page view. Otherwise the visitor gets two stacked interruptions.
Behavior

Selection

Every row is a real link (<a href>) to that country's site or locale. One click selects the country: there is no confirm button and no selected state, and the panel closes as navigation starts. Because the rows are links, keyboard (Tab / Enter), middle-click and "open in new tab" all work without extra code.

JS
// Production rows carry the country URL, so the default navigation runs.
// Prototype rows use href="#", so this only closes the panel.
function selectCountry(el, e) {
  if (el.getAttribute('href') === '#') e.preventDefault();
  closeCountryPanel();
}
ℹ️
Unlike the Wholesaler Picker, rows have no external-link icon. The destination is another UFS site, not a third-party shop, so no "you're leaving" cue is needed.
Behavior

Dismiss

The panel cannot be dismissed. There is no close button, a click on the backdrop does nothing and Esc is ignored: picking a country is the only way out. The backdrop stays on screen purely as a dim layer. Nothing is stored, so in markets that need it the panel opens on every full page load until the visitor picks a country (and is sent to that country's site).

⚠️
Do not wire closeCountryPanel() to the backdrop, an X button or a keydown handler. Unlike Sign-in, Filters or the Wholesaler Picker, which share this drawer shell, the Country Selector is a forced choice. closeCountryPanel() is called only from selectCountry().
Variants

Country List

The list is market data, not a fixed set. Any number of rows works: .signin-panel-body already scrolls (overflow-y: auto) once the list is taller than the viewport, and the header stays pinned. Long names such as "United Arab Emirates" sit on one line at 420px and wrap cleanly on narrow phones, since the name column is flexible and the flag tile doesn't shrink.

Flag assets: exported from Figma at 4× into images/flags/. Each PNG already has its rounded corners and light border baked in, so it goes into the tile as-is. Flags are decorative (alt="") because the country name next to them is the accessible label.

Internationalisation

i18n & RTL

No component-specific RTL rules are needed. The drawer shell already slides in from the left under dir="rtl", and the header and rows are plain flexbox, so the logo and flag tile mirror automatically. Title, description and each country name go through the same data-i18n / data-i18n-aria keys as the rest of the prototype (cs-title, cs-desc, cs-<iso>). Translate country names per locale rather than showing them in their own language.
