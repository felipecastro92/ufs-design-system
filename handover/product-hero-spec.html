Product Hero

A PDP-style hero: an image gallery (zoomed main image, thumbnail rail, orange active-indicator, desktop-only prev/next arrows, swipe on mobile) beside a product info panel (eyebrow, title, USP list, "more info" link, large CTA, SKU, and a Download/Print/Email utility bar). Max-width 1240px, always centred.

Anatomy & Rules

Two flex children — .ufs-product-hero__gallery and .ufs-product-hero__info — sitting side by side, each flex: 1 1 0 so they split the row exactly 50/50 regardless of content, gap var(--space-20) (80px), capped at 1240px and centred. Desktop only — the mobile breakpoint below already fully overrides both to a stacked, full-width layout.

Product Hero

Gallery Interaction

One mechanism drives every entry point: .ufs-product-hero__main-track is a scroll-snap container with one full-width frame per image. Thumbnail clicks and arrow clicks both just scrollTo() the track; mobile swipe is the browser's own native touch-scroll on that same track — nothing custom to break. A scroll listener (throttled via requestAnimationFrame, same pattern as Flex Carousel) reads back the nearest snapped index and syncs the active thumbnail, the orange indicator, and the arrows' disabled state.

Why this instead of a JS-swapped single <img>

A common alternative is one <img> whose src gets swapped on click, with swipe handled by separate touchstart/touchmove/touchend math. That's two parallel implementations of "which image is showing" that have to be kept in sync. A scroll-snap track collapses both into a single scrollLeft value — swipe is free (native browser behaviour), and clicking a thumbnail or arrow is just a smooth-scroll to that frame's offset.

ℹ️
Thumbnail count is not fixed at 5 — the JS reads however many .ufs-product-hero__thumb / .ufs-product-hero__main-frame pairs are present at init. Keep the two lists the same length and order.
Variants

CTA Variants

Default is a single primary CTA. The dual-CTA variant wraps a primary and a secondary button in .ufs-product-hero__ctas — both share the existing .ufs-product-hero__cta class (so both pick up its mobile full-width rule; the wrapper itself also needs its own explicit width:100% at that breakpoint, since .ufs-product-hero__info's align-items:flex-start would otherwise shrink-wrap it to content width) and differ only via the standard .btn-primary / .btn-secondary modifiers. Primary always leads (left on desktop, top on mobile). This is the default in template-product-bin.html ("How to order" primary + "Contact us" secondary); the single-CTA form documented above stays the component's baseline for any other product-hero instance.

Responsive

Mobile Examples

Below 768px: gallery stacks above the info panel (both full-width), arrows are hidden entirely, and the main image is swipeable directly (plus tapping any thumbnail still jumps to it). The gallery's own internal gap tightens from 16px to 8px, and the title drops from --text-h2 (36px) to --text-h3-mob-size (24px) — matching Figma's mobile frame, every other type size (USPs, link, SKU, utility bar) stays the same across both breakpoints.

Internationalisation

i18n & RTL

The gallery/info split, and everything inside each column, is flex-based and mirrors automatically under dir="rtl". The two things that don't come for free — because they're physically positioned, not flex children — are the arrows (absolutely positioned left/right over the image) and their chevron direction; both get an explicit override below. The active-indicator bar (left:0; right:0) is symmetric and needs nothing.

Usage

The gallery needs one JS call per instance, passing the track/thumbs/arrow elements — initProductHeroGallery() is defined in the <script> at the bottom of this page and is what wires the three live demos above.

// One call per .ufs-product-hero instance on the page
function initProductHeroGallery(root) {
  var track  = root.querySelector('.ufs-product-hero__main-track');
  var thumbs = root.querySelectorAll('.ufs-product-hero__thumb');
  var prev   = root.querySelector('.ufs-carousel-arrow--prev');
  var next   = root.querySelector('.ufs-carousel-arrow--next');

  function goTo(i) { track.scrollTo({ left: i * track.clientWidth, behavior: 'smooth' }); }

  thumbs.forEach(function(t, i) { t.addEventListener('click', function() { goTo(i); }); });
  prev.addEventListener('click', function() { goTo(activeIndex() - 1); });
  next.addEventListener('click', function() { goTo(activeIndex() + 1); });

  function activeIndex() { return Math.round(track.scrollLeft / track.clientWidth); }
  function sync() {
    var i = activeIndex();
    thumbs.forEach(function(t, idx) { t.classList.toggle('is-active', idx === i); });
    prev.disabled = i <= 0; next.disabled = i >= thumbs.length - 1;
  }
  track.addEventListener('scroll', function() { requestAnimationFrame(sync); }, { passive: true });
  sync();
}
document.querySelectorAll('.ufs-product-hero').forEach(initProductHeroGallery);
