Video Embed

A tile-like video thumbnail: full-bleed background image with a bottom gradient overlay, a centered play button, and a video title + duration pinned to the bottom. Two required size modifiers — --tile, a 350px 4:3 carousel card, and --wide, a 650px 16:9 featured variant — both with centered content. Clicking the play button opens the DS's existing shared video lightbox.

Play Trigger & Lightbox

Clicking the play button opens the same shared video lightbox modal already used by Teaser and Training Hero — not a new modal. The button carries the video URL via data-video-url; a single shared script (see Usage) reads it and opens .lb-overlay.

Only the play button is the click target, not the whole card — same touch-vs-mouse distinction as Teaser: on mouse/trackpad the hit area covers the full photo (easy to click anywhere), but on touch it's scoped to just the icon, via a touch-action: pan-x fallback, so a swipe starting on the card still reaches the carousel track's native horizontal scroll instead of being swallowed by the button.
Trigger.ufs-video-embed__play<button>, absolutely positioned
Modal.lb-overlay / .lb-panelshared with Teaser & Training Hero — one instance per page, not duplicated per card
Video URL[data-video-url]read by the shared lightbox script's click listener
CloseEsc, backdrop click, × buttonsame three dismiss paths as every other DS lightbox

Sizes

Two required modifiers — every instance needs one or the other, there's no bare unmodified default. .ufs-video-embed--tile is a fixed-width flex-carousel card (350px, 4:3); .ufs-video-embed--wide is a wider featured variant (650px, 16:9, desktop only) with a bigger play icon and title. Content stays centered on both.

Hover Behavior

Two independent hover effects, layered: hovering anywhere on the card zooms the background photo 1.06× (Topic Tile's whole-card pattern) — hovering the play button itself additionally darkens its circle and scales it 1.08×. Mouse/trackpad only, gated behind (hover: hover) and (pointer: fine) so nothing sticks on touch.

Internationalisation

i18n & RTL

Both variants need no RTL-specific handling at all — content is centered on --tile and --wide alike, so there's no physical left/right edge to mirror under dir="rtl".

RTL — wide variant

💡
The play button itself needs no RTL handling either — it's centered via top/left: 50% + translate(-50%,-50%), and full-cover (inset:0) on desktop, neither of which reference a physical left/right edge. The icon's own margin-top is a vertical (block-direction) offset, so it's unaffected by RTL too — only inline-direction values (left/right, padding-inline-*) need a mirroring check.

// Same shared lightbox script every video trigger on the page reuses —
// only needs to run once. Skip entirely if Teaser or Training Hero
// already wire it up on this page.
(function () {
  var lbOverlay = document.getElementById('lb-overlay');
  var lbIframe  = document.getElementById('lb-iframe');
  var lbClose   = document.getElementById('lb-close');
  if (!lbOverlay) return;

  function openLB(url) {
    lbIframe.src = url;
    lbOverlay.classList.add('open');
    document.body.style.overflow = 'hidden';
  }
  function closeLB() {
    lbOverlay.classList.remove('open');
    lbIframe.src = '';
    document.body.style.overflow = '';
  }

  document.querySelectorAll('[data-video-url]').forEach(function (trigger) {
    trigger.addEventListener('click', function () { openLB(trigger.getAttribute('data-video-url')); });
  });
  lbClose.addEventListener('click', closeLB);
  lbOverlay.addEventListener('click', function (e) { if (e.target === lbOverlay) closeLB(); });
  document.addEventListener('keydown', function (e) { if (e.key === 'Escape' && lbOverlay.classList.contains('open')) closeLB(); });
})();
