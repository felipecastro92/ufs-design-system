Product Tip

A row of short trust/benefit cards (bold title + one-line description) that fully responsively accommodates 2, 3, 4 or 5 cards per row on desktop, and — past 5 — automatically balances the overflow across additional rows instead of leaving an awkward short last row. Stacks to a single full-width column on mobile.

Anatomy & Rules

Three nested pieces: .ufs-product-tips-rows (the whole component — a vertical stack of one or more rows), .ufs-product-tips (one row), and .ufs-product-tip (one card). Every card in a row is flex: 1 1 0, so 2, 3, 4 or 5 cards in the same row divide it evenly with no per-count CSS — the row simply has as many children as it's given.

Product Tip

Row-Split Rule

Desktop rows hold a maximum of 5 cards. Below 5 items there's nothing to decide — one row, done. Past 5, the naive approach (fill each row to 5, dump whatever's left into a final short row) produces lopsided results like 5+1 or 5+2. Instead, the total is split as evenly as possible across the fewest rows that still respect the 5-per-row cap, with any remainder going to the earliest rows.

The formula

Run once per instance, in renderProductTips() (see Usage).

JS
var rows      = Math.ceil(tips.length / 5);              // fewest rows that keep every row ≤5
var base      = Math.floor(tips.length / rows);       // even split size
var remainder = tips.length % rows;                  // how many rows need one extra card
// the first `remainder` rows get (base + 1) cards; the rest get `base`
ℹ️
1–5 items always render as a single row — the formula only starts producing more than one row once tips.length > 5.
Worked examples
6 items rows = ceil(6/5) = 2 → 3 + 3
7 items rows = ceil(7/5) = 2 → 4 + 3
8 items rows = ceil(8/5) = 2 → 4 + 4
11 items rows = ceil(11/5) = 3 → 4 + 4 + 3
💡
The pattern generalises past these examples too — e.g. 9 items → 5 + 4, 10 → 5 + 5, 13 → ceil(13/5)=3 rows → 5 + 4 + 4. If a designer hands you a specific N not shown here, run it through the formula above rather than guessing.
Responsive

Mobile Examples

Below 768px, row grouping stops mattering — every card in every row collapses into one continuous full-width vertical stack with a single consistent 16px gap throughout (.ufs-product-tips-rows and every .ufs-product-tips inside it both switch to the same flex-direction: column; gap: var(--space-4)). A 7-card component still renders as one flat stack of 7 on mobile, even though it was two rows (4+3) on desktop — the row-split rule is a desktop-only concept.

Internationalisation

i18n & RTL

Every layer of this component — the row, the cards inside it, the title/description stack inside each card — is a plain flex-direction: row or column flexbox with no physically-positioned children (no left/right, no fixed-side arrows like the Product Hero's gallery has). Flexbox's row axis is direction-relative, not physical, so it mirrors automatically under dir="rtl" — the first card in markup order still renders first in reading order, just right-to-left. No component-specific RTL overrides are needed.

ℹ️
The card background, border and text colours are all symmetric (equal on every side, or a flat fill), so nothing about the card itself needs a [dir="rtl"] selector either — unlike components with an offset shadow, a one-sided accent border, or absolutely-positioned controls.
Developer

Usage

Unlike most components in this DS, Product Tip's markup is generated by JS rather than hand-authored per page — the row split has to be computed from however many tips the page passes in, so hand-splitting invites mistakes as content changes. Give the page a single empty mount point (<div class="ufs-product-tips-rows" id="..."></div>) and call renderProductTips() with your data.

// One call per .ufs-product-tips-rows mount point on the page
function renderProductTips(containerId, tips, footnote) {
  var container = document.getElementById(containerId);
  if (!container) return;
  var rows      = Math.ceil(tips.length / 5);
  var base      = Math.floor(tips.length / rows);
  var remainder = tips.length % rows;
  var html = '';
  var i = 0;
  for (var r = 0; r < rows; r++) {
    var size = base + (r < remainder ? 1 : 0);
    html += '<div class="ufs-product-tips">';
    for (var c = 0; c < size; c++) {
      var tip = tips[i++];
      html += '<div class="ufs-product-tip">' +
        '<p class="ufs-product-tip__title">' + tip.title + '</p>' +
        '<p class="ufs-product-tip__desc">' + tip.desc + '</p>' +
        '</div>';
    }
    html += '</div>';
  }
  if (footnote) html += '<p class="ufs-product-tips__footnote">' + footnote + '</p>';
  container.innerHTML = html;
}

// Example: a 7-tip product renders as a 4+3 split automatically
renderProductTips('product-tips-rows', [
  { title: 'No added MSG', desc: 'Full-bodied flavour built from real ingredients.' },
  { title: 'Consistent every batch', desc: 'Standardised seasoning, every time.' },
  // … 5 more tips
], '*Optional footnote text.');
