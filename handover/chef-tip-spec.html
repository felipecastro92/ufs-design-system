Chef's Tip

An expandable/collapsible panel that sits between Preparation and the Utility Bar on the recipe detail page. Collapsed by default: heading + 2-line-clamped body + "Read more". Expanding reveals a photo, a "Go to" link and a secondary-button CTA, and swaps the toggle to "Read less".

Full Component Preview

The live component, exactly as it ships on template-recipe-detail.html — same copy, same DS secondary button, same toggle behavior. Collapsed by default; click "Read more" below to expand it.

Chef's tip

Keep it lump-free at scale

Whisk MEADOWLAND Professional into hot milk before folding it through the potatoes — adding it cold or straight from the block is the most common cause of lumps when this recipe is scaled up for bulk service. For an extra glossy finish under the bain-marie, stir in a knob of butter just before service rather than during mixing.

Internationalisation

i18n & RTL

The card itself is a plain flex column with no physical left/right values, so it mirrors automatically. The one exception is the eyebrow pill, which overlaps a corner rather than sitting in-flow.

المزيد من نصائح الشيف
💡
The pill's own position uses inset-inline-start rather than left — the one physical-direction value the original build shipped with, since a corner-overlapping badge doesn't get mirrored for free the way an in-flow flex row does. That's a fix made specifically for this spec; the same logical property now ships in template-recipe-detail.html too.

function toggleChefTip(btn) {
  var tip = document.getElementById('chef-tip');
  var expanded = tip.classList.toggle('is-expanded');
  btn.textContent = expanded ? btn.dataset.lessLabel : btn.dataset.moreLabel;
  btn.setAttribute('aria-expanded', expanded ? 'true' : 'false');
  if (!expanded) btn.scrollIntoView({ block: 'nearest', behavior: 'smooth' });
}
