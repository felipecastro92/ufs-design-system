Design System / Teaser
Handover Spec

Teaser & Teaser LG

Two related promotional components. Teaser stacks 2, 3 or 4 cards horizontally across a 1240px-max wrapper (never 1); Teaser LG is a single 50/50 text-and-image module. Both support white, mushroom-100 and squid-ink backgrounds, collapse to a single mobile layout, and are fully RTL-aware.

Format·HTML + CSS
Overview

Full Component Preview

Teaser: <div class="ufs-teaser-wrapper ufs-teaser-wrapper--2/--3/--4"> holding 2, 3 or 4 .ufs-teaser cards — image, optional eyebrow, mandatory title, optional description, optional CTA (a filled button in the 2-up variant, a plain text link in 3-up/4-up — the CTA's visual type is locked to the wrapper size, not a free per-card choice). Teaser LG: a single .ufs-teaser-lg with text and image each taking an equal 50% share of the same 1240px-max wrapper. Both live inside a full-bleed section (.pg-teaser-section / .pg-teaser-lg-section) that supplies the background colour and page-edge padding.

Teaser (grid) · Structure

Anatomy & Rules

Every card is .ufs-teaser: an image, then .ufs-teaser__body holding an eyebrow, a .ufs-teaser__heading group (title + description) and a CTA. Wrapper size and CTA type are linked — pick the wrapper, the CTA style follows.

Sizing & CTA-type rules
These are structural constraints, not styling preferences — the markup should not deviate from them.
Wrapper modifiers--2 / --3 / --4Only these three. No 1-card wrapper exists — use Teaser LG instead.
--2 card countexactly 2grid-template-columns: repeat(2, 1fr)
--3 card countexactly 3grid-template-columns: repeat(3, 1fr)
--4 card countexactly 4grid-template-columns: repeat(4, 1fr)
--2 CTA.btn.btn-primaryAlways a filled button, never a text link
--3 / --4 CTA.ufs-teaser__linkAlways a plain underlined text link, never a button
Wrapper max-width1240pxmargin-inline: auto — always centred
Field optionality
ImagemandatoryAspect ratio and radius are wrapper-size-specific, see below
Eyebrowoptional--text-overline bundle, color: var(--color-mushroom-900)
TitlemandatoryOnly field that can never be omitted
Descriptionoptionalcolor: var(--color-brand-dark)
CTAoptionalType (button/link) is locked to wrapper size when present

<div class="ufs-teaser-wrapper ufs-teaser-wrapper--2">

    <div class="ufs-teaser__body">
      <p class="ufs-teaser__eyebrow">Onboarding</p>  <!-- optional -->

</div>

Teaser LG · Structure

Anatomy & Rules

.ufs-teaser-lg holds .ufs-teaser-lg__text and .ufs-teaser-lg__image as two equal 50% flex children, gap var(--space-14) (56px) on desktop. Unlike the grid Teaser, the CTA here is always a filled button — there is no text-link alternative.

Rules
Text : image ratio50% : 50%flex: 1 on both sides
Desktop gapvar(--space-14)56px
Mobile gapvar(--space-6)24px, image moves on top
CTA.btn.btn-primaryAlways a filled button — no text-link variant
Image position.ufs-teaser-lg--image-leftDefault is image-right; modifier reverses via flex-direction: row-reverse
Wrapper max-width1240pxSame cap as the grid Teaser, on a full-bleed section
HTML
<section class="pg-teaser-lg-section pg-teaser-lg-section--mushroom">
  <div class="ufs-teaser-lg">  <!-- add --image-left to flip sides -->
    <div class="ufs-teaser-lg__text">
      <div class="ufs-teaser-lg__content">
        <p class="ufs-teaser-lg__eyebrow">…</p>  <!-- optional -->
        <h2 class="ufs-teaser-lg__title">…</h2>
        <p class="ufs-teaser-lg__desc">…</p>  <!-- optional -->
      </div>
      <a href="#" class="btn btn-primary ufs-teaser-lg__cta">…</a>  <!-- optional -->
    </div>
    <div class="ufs-teaser-lg__image"><img src="…" alt=""/></div>
  </div>
</section>

Responsive

Mobile Examples

Below 768px, Teaser collapses to a single-column bordered list: image shrinks to a fixed 120px-wide thumbnail (same aspect ratio as its desktop size — only the width is capped, so the ratio is never distorted), sits left of the content, and every card gets a border-bottom divider except the last. Teaser LG stacks the image on top full-width regardless of its desktop image-left/right setting, using flex-direction: column-reverse rather than column — since markup order is always text-then-image, a plain column would put the image at the bottom for the default (image-right) variant.

Internationalisation

i18n & RTL

Every layout mechanism in both components is flex or grid, and neither uses a literal text-align: left or a physical left/right position anywhere — so column order, CTA order and text alignment all auto-mirror under dir="rtl" with zero additional CSS. This includes Teaser LG's --image-left modifier: row/row-reverse both auto-mirror the same way.
