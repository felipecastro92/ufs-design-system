Ingredients Panel

The left column of a Recipe Detail page: a title, a servings stepper that live-recalculates every ingredient quantity, grouped ingredient rows, and one expandable row that reveals an inline product tile for a branded UFS ingredient (MEADOWLAND Professional). Ends in a single full-width CTA.

States

Servings & Expandable Row

Two independent interactions: the servings stepper rescales every [data-base-qty] quantity relative to [data-base-servings], and the linked ingredient row toggles its disclosure panel — both live in the Overview demo above.

Servings scaling

Rounding is precision-aware: whole numbers above 10 (kitchen quantities don't need decimals at that scale), one decimal place below it — so small seasoning amounts like "4 g" don't collapse to a "0 g"/"1 g" step that loses the recipe's ratio.

Mobile Example

Internationalisation

i18n & RTL

Every row is a plain flex row of symmetric, unpositioned children — no left/right values anywhere in this component. It mirrors automatically under dir="rtl" with zero extra CSS: the quantity stepper's +/- buttons swap sides, the expand chevron stays trailing, and the nested product tile's own favourite/badge corners flip via its existing RTL rules (see tiles-spec.html).

Usage

Two JS functions drive the interactivity: a servings-stepper handler that rescales every [data-base-qty] element within the same panel, and a generic disclosure toggle for the expandable ingredient row.

// Servings stepper — scoped to the panel it lives in, so multiple
// instances on one page (as in this doc) never cross-scale each other
function stepServings(qtyEl, delta) {
  var valueEl = qtyEl.querySelector('.fi-qty-value');
  var base = parseInt(qtyEl.dataset.baseServings, 10);
  var current = parseInt(valueEl.textContent, 10);
  var next = Math.max(1, current + delta);
  if (next === current) return;
  valueEl.textContent = next;
  qtyEl.querySelector('[aria-label*="ecrease"], [aria-label*="قليل"]').disabled = (next <= 1);
  qtyEl.closest('.ufs-recipe-ingredients').querySelectorAll('[data-base-qty]').forEach(function(el) {
    var baseQty = parseFloat(el.dataset.baseQty);
    var unit = el.dataset.unit;
    var scaled = baseQty * next / base;
    var rounded = scaled >= 10 ? Math.round(scaled) : Math.round(scaled * 10) / 10;
    el.textContent = rounded + ' ' + unit;
  });
}

// Expandable ingredient row — generic disclosure toggle
function toggleIngredientRow(trigger) {
  var row = trigger.closest('.ufs-ingredient-row');
  var isOpen = row.classList.toggle('is-open');
  trigger.setAttribute('aria-expanded', isOpen ? 'true' : 'false');
}
