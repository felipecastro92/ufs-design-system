Utility Bar

A slim Download / Print / Email action row: three icon-and-label buttons, each icon in its own mushroom-100 circle, evenly spaced across a strip bordered top and bottom. Decorative by default — no click handlers wired in the shipped templates.

Utility Bar

Anatomy & Rules

display:flex; justify-content:space-evenly across the full width of whatever column it sits in, so three items spread evenly rather than clustering to one side. Each button is icon-over-label on mobile, icon-beside-label on desktop.

Bar
Border1px solid var(--color-mushroom-300)top and bottom — no side borders
Padding (desktop)var(--space-2) var(--space-6)8px vertical, 24px horizontal
Padding (mobile)var(--space-3) var(--space-4)12px vertical, 16px horizontal
Layoutjustify-content: space-evenlywidth:100% — spaces items across the parent column's own width, not a fixed frame
Button
Gap (icon↔label)var(--space-3)desktop row layout only — mobile stacks icon over label with the same gap token
Paddingvar(--space-2)hit-area padding around icon+label as a unit
Corner radiusvar(--space-2)on the button's own hover background
Labelvar(--text-body-size)16px desktop → var(--text-body-sm-size) 14px mobile, color var(--color-brand-dark)
Icon circlevar(--space-14)56px desktop → var(--space-10) 40px mobile, radius-full, bg var(--color-mushroom-100)
Icon imagevar(--space-5)20px desktop → var(--space-4) 16px mobile

Hover & Focus

The mushroom-100 fill swaps sides on hover: it moves from the icon circle onto the outer button, and the icon circle itself goes to white — rather than a flat single-surface darken. Keyboard focus reuses the same swap plus a visible outline.

Default
Hover (forced for this preview — try hovering the live demo above)
Focus-visible (forced for this preview — try tabbing to the live demo above)
Key Tokens
Hover / focus bgvar(--color-mushroom-100)on .ufs-utility-bar__btn
Hover / focus icon bgvar(--color-salt)on .ufs-utility-bar__icon — swaps with the button's own fill
Focus outline2px solid var(--color-brand-dark)offset 2px, :focus-visible only (not on mouse click)
Responsive

Mobile Example

Below 768px each button becomes flex:1 0 0 (equal-width columns filling the bar) and stacks icon over label, dropping the label to --text-body-sm-size and shrinking the icon circle from 56px to 40px.

Internationalisation

i18n & RTL

Purely a flex row of symmetric, unpositioned children — no left/right values anywhere in the component. It mirrors automatically under dir="rtl" with zero extra CSS.

RTL
💡
No [dir="rtl"] override rule exists for this component anywhere in the codebase — none is needed.

Usage

Static markup, no JS required. Buttons ship decorative (no onclick) in both templates — wire your own Download/Print/Email handlers per page.
