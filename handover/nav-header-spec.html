Overview

Full Header Preview

The header is a stack of independent, swappable rows: a persistent utility bar, the primary nav (logo, links, search, actions), and — on interaction — a megamenu, search overlay, sign-in or profile panel. On mobile the utility bar and primary nav collapse into a single compact mobile nav bar, with search and navigation moved into dedicated overlays/drawers.

ℹ️
This spec documents markup and CSS as implemented in the live prototype. It does not distinguish CMS-editable vs. fixed content — that mapping is a separate exercise for the CMS integration team.
🎨
3 colour contexts
Every row ships --light, --dark and --glass modifiers, switched per page context (e.g. glass over a hero image, light on interior pages).
📱
Independent breakpoint
Utility bar + primary nav (.ufs-util, .ufs-nav) are desktop-only; mobile nav (.ufs-mnav) is its own component, not a squeezed version of the desktop bar.
🧭
Journey-aware
Landing, registration and checkout flows swap in reduced-chrome header variants (minimal header, sticky CTA, named-step checkout progress) via body-level context classes.
