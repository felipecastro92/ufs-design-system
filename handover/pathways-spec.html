Design System / Pathways
Handover Spec

Pathways

A heading over a row of colour-coded shortcut cards — icon, label, and (desktop only) a trailing chevron. Desktop: fixed-width cards centred as a group, 3 or 4 up. Mobile: left-aligned, horizontal icon+label cards, no chevron, scrolling horizontally as one track.

Anatomy & Rules

A heading, then a row of cards. Each card is icon + label + (desktop only) chevron — the chevron isn't hidden on mobile, it's genuinely absent from that Figma frame; the horizontal-scroll row itself already signals "more this way" at that size.

Colour Variants

Four fixed card colours, each with its own icon/chevron tint for contrast — not a generic single card style. All four resolve to exact DS tokens (see notes).

--auberginevar(--color-aubergine)#5C3657 — exact match, white icon/label
--squidvar(--color-brand-dark)#221D37 — Figma's "squid-ink" is this DS's brand-dark, not --color-squid-900 (a different, darker step) — same substitution .ufs-flex-carousel--squid already makes. White icon/label
--orangevar(--color-accessible-orange)#D14900 — exact match, white icon/label
--smokecolor-mix(in srgb, var(--color-smoke) 50%, transparent)--color-smoke (#94889D) at 50% opacity — lands within a rounding point of Figma's #C9C3CE on a white surface. Dark icon/label (no filter)

3 vs 4 Cards

No separate size variant — card width (250px) and row gap (32px) are constant. The row's total width, and how it centres, is simply a function of card count: 3 cards is 814px (3×250 + 2×32), 4 cards is 1096px (4×250 + 3×32), both from the real Figma frames.

Responsive

Mobile Example

Below 768px: heading and row both go left-aligned, cards flip to a horizontal icon+label row with no chevron, and the row becomes a horizontally-scrolling track — swipe to see the rest. This scroll-track behavior isn't in the source Figma frame (it only shows the row assuming it fits); it's this spec's own addition, built the same way every other fixed-width-card carousel in this DS already works.

Internationalisation

i18n & RTL

The chevron uses inset-inline-end (not right) and gets an explicit scaleX(-1) flip under dir="rtl", so it still points toward the reading-direction "next" edge. The mobile heading's text-align:left needs the same explicit flip real spec files in this DS always give literal text-align values. The horizontally-scrolling row needs no JS changes — native overflow-x:auto already starts scrolled to the trailing edge under RTL.

Usage

Pure HTML + CSS — no JS. Cards are real <a> links, not buttons, since a Pathway is always a navigation shortcut.

<div class="ufs-pathways">
  <h2 class="ufs-pathways__heading">Heading text</h2>
  <div class="ufs-pathways__list">
    <a href="…" class="ufs-pathways__card ufs-pathways__card--aubergine">
      <div class="ufs-pathways__icon"><img src="icons/products.svg" alt=""/></div>
      <span class="ufs-pathways__label">Label</span>
      <span class="ufs-pathways__chevron" aria-hidden="true"><svg viewBox="0 0 7 14"><path d="M1 1l5 6-5 6" stroke="currentColor"/></svg></span>
    </a>
    <!-- 2 to 5+ cards, --aubergine / --squid / --orange / --smoke -->
  </div>
</div>
