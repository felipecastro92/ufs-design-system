Structure

Anatomy & Interaction

A family of content-summary cards sharing one base — image (with an optional badge and favourite toggle), then a body of eyebrow / title / rating / meta, then an optional CTA. Six content types compose the same shared .ufs-tile classes differently, so the differences between them are purely which optional pieces are present, not different CSS. Topic Tile is the one exception: a full-bleed hero/CTA card rather than a content summary, so it doesn't share the base.

Anatomy — shared base

Every tile below (except Topic) is built from these classes. A type either includes or omits __eyebrow, __rating, __meta and __cta — nothing here is type-specific CSS, so none of the 6 cards further down need their own stylesheet beyond this.

One component, context-dependent width and layout — not separate variants: in the flex-carousel, .ufs-tile always renders as the card below, at a fixed width, at every viewport. In a catalog grid it's the same card at a flexible width from 769px up; below 768px, wrapping the grid in .ufs-catalog-grid reflows the same markup into a compact row (image left, content right) — no new HTML, no separate component to choose. Each of the 5 content-summary tiles below shows this reflowed state labeled “Catalog grid — ≤768px”.

Interaction

Hovering the tile lifts it with a shadow + translateY(-2px) — the same treatment already used for product cards elsewhere in this DS, applied consistently across all 6 types (Topic gets a larger shadow only, no lift, since it's already a large full-bleed block). The favourite button toggles independently of the tile's own click-through (event.stopPropagation()), so tapping the heart never also triggers navigation. Try both on any live specimen on this page.

Variants

Tile Types

Seven content types. Six share the vertical .ufs-tile anatomy above — no per-type CSS beyond what's already documented — and each shows both its fixed-width flex-carousel form and its reflowed inline row form (the same markup, restyled by .ufs-catalog-grid below 768px). Brand Tile is carousel-only with its own horizontal layout, closer to Topic Tile in that it carries its own CSS rather than reusing the shared vertical base.

Internationalisation

i18n & RTL

Two physical-position values need an explicit flip under dir="rtl": the favourite button and the badge. In the inline (catalog-preview) layout, the image column also swaps sides — but that's grid-template-areas/-columns auto-mirroring under dir="rtl" on its own, the same direction-aware column numbering flexbox uses, so no override is needed there.

RTL

Two physical-position values need an explicit [dir="rtl"] flip: the favourite button (top-right → top-left) and the badge (top-left → top-right). In the inline (catalog-preview) layout, the image column also swaps sides so it stays on the reading-start edge. Everything else — flex rows, centered text — reverses automatically. Shown here on the default (vertical) tile and the inline (catalog-preview) row; identical CSS applies to all 6 content types and the real .ufs-catalog-grid .ufs-tile reflow.
