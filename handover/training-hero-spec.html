Training Hero

Full-bleed two-panel hero for course/training pages: a 40%-width dark content panel (eyebrow, title, description, instructor byline, CTA) beside a photo panel with a dark overlay, a favourite toggle, and a "Watch trailer" control that opens the DS's shared video lightbox. Below 768px the panels stack, photo on top.

Anatomy & Rules

A fixed 40% / flex-1 split — the content panel never grows past 40% of the row regardless of copy length, and the photo fills whatever's left. Squid-500 (var(--color-brand-dark)) background throughout; every text node inside the content panel is Salt (white) or brand-primary (eyebrow only).

States

Favourite & Trailer Hover

Two interactive states live on the media panel: the favourite heart toggles filled/outline via toggleTileFav(), and hovering the trailer control darkens its icon circle, scales it 1.08×, and zooms the photo behind it 1.06× via a :has()-scoped selector — the zoom only fires while the trailer itself is hovered, not anywhere else on the photo.

Favourite — default vs. active
Key Tokens
Active fillvar(--color-brand-primary)on .ufs-tile__fav.is-active svg path — both fill and stroke
Favourite popufs-tile-fav-pop 0.32sscale 1 → 1.5 → 0.9 → 1, fires only on false→true (not on removal)
Trailer hover iconrgba(0,0,0,0.4) + scale(1.08)up from the resting rgba(0,0,0,0.25)
Trailer hover photo zoomscale(1.06)via .ufs-training-hero__media:has(.ufs-training-hero__trailer:hover) — hover the "Watch trailer" control in the Overview demo above to see it live

Internationalisation

i18n & RTL

The panel/media split and everything flowing inside each is flex-based and mirrors automatically. The content panel's padding uses logical properties (padding-inline-start/-end) so it flips for free. The one physically-positioned element is the favourite button (top/right), which gets an explicit [dir="rtl"] override.

Usage

Two small JS hooks power the interactive parts: toggleTileFav() (shared with every .ufs-tile__fav instance across the DS — see tiles-spec.html) and the shared video lightbox (openLB()/closeLB(), wired to any [data-video-url] trigger — see teaser-spec.html#video for the reference implementation). Adding this hero to a page that doesn't already use the lightbox elsewhere means porting the .lb-overlay markup + JS too.

// Favourite toggle — shared across every .ufs-tile__fav on the page
function toggleTileFav(btn, event) {
  if (event) event.stopPropagation();
  var active = btn.classList.toggle('is-active');
  btn.setAttribute('aria-pressed', active ? 'true' : 'false');
  if (active) {
    // pop animation + 6-line splash burst — see tiles-spec.html for the full sequence
  }
}

// Video lightbox — shared by every [data-video-url] trigger
(function () {
  var lbOverlay = document.getElementById('lb-overlay');
  var lbIframe  = document.getElementById('lb-iframe');
  function openLB(url) { lbIframe.src = url; lbOverlay.classList.add('open'); document.body.style.overflow = 'hidden'; }
  function closeLB() { lbOverlay.classList.remove('open'); lbIframe.src = ''; document.body.style.overflow = ''; }
  document.querySelectorAll('[data-video-url]').forEach(function (trigger) {
    trigger.addEventListener('click', function () { openLB(trigger.getAttribute('data-video-url')); });
  });
})();
