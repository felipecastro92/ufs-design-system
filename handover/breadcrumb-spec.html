Breadcrumb

Interior-page trail navigation — full trail on desktop, collapsed "…" dropdown on mobile. Structure, states, responsive rules and i18n/RTL, documented for implementation.

Overview

Full Component Preview

A single <nav class="ufs-breadcrumb"> — an ordered list of levels separated by a small chevron, ending in the current (non-linked) page. It's an independent, swappable row that renders directly below the header on interior pages (category / PLP / PDP) — never on the true homepage, since the homepage has no parent trail to show.

Structure

Anatomy

One <ol>, each level an <li> containing either a link (.ufs-breadcrumb__link) or, for the last item, plain text (.ufs-breadcrumb__current, aria-current="page" — never a link, per accessibility best practice). A chevron .ufs-breadcrumb__sep sits between every pair of levels.

⚠️
No overflow-x: auto safety-net scroll on .ufs-breadcrumb__list — deliberately. Adding one clips the mobile dropdown, because overflow-x: auto implicitly computes overflow-y as auto too (per the CSS overflow spec), and the dropdown needs to render outside this row. This is safe because the mobile collapse below guarantees only 3 top-level items ever show (Home, "…", Current) — always fits, never needs to scroll.
Structure

States & Trail Length

The middle-collapse pattern should only trigger when there's something meaningful to hide. A short trail (2–3 levels total) fits fine on any screen and should render in full, uncollapsed, on mobile too — collapsing a single level into "…" saves no space and just adds a tap.

Short trail (2 levels) — no collapse needed, renders identically on mobile
  1. Home
  3. Recipes
Long trail (4 levels) — desktop shows all of it in full
  1. Home
  3. Products
  5. Sauces & Condiments
  7. Ketchup & Tomato Sauces
💡
This threshold isn't automatic — it's a template/CMS decision: only wrap middle levels in .ufs-breadcrumb__mid (and populate the .ufs-breadcrumb__drop dropdown) when there are 2 or more levels between Home and the current page. With exactly one middle level, render it as a normal, always-visible item — three total crumbs fit any mobile width without crowding, so collapsing it would only cost a tap for no space saved.
Responsive

Mobile Collapse & Dropdown

Below 768px, every .ufs-breadcrumb__mid item (and its chevron) is hidden, and .ufs-breadcrumb__collapsed — a "…" trigger plus its dropdown, both hidden on desktop — is revealed instead. Tapping "…" opens a small card listing the hidden levels as real links, positioned and animated the same way as the utility bar's language dropdown for visual consistency. The Home crumb also swaps its text label for a 14×14px home icon at this breakpoint (.ufs-breadcrumb__home-icon/.ufs-breadcrumb__home-text toggle visibility) — the word "Home" stays available to screen readers via aria-label on the link.

Why the dropdown needs its own DOM position
A layout gotcha worth flagging for anyone extending this component.
Trigger + dropdown wrapperposition: relative.ufs-breadcrumb__collapsed — the dropdown's containing block
Dropdownposition: absolute; z-index: 300escapes the row's own height
List overflowvisible (not auto)see the warning in Anatomy — auto clips the dropdown
JS
function closeBreadcrumbDrop() {
  document.querySelectorAll('.ufs-breadcrumb__collapsed.is-open').forEach(function(w) {
    w.classList.remove('is-open');
    var btn = w.querySelector('.ufs-breadcrumb__ellipsis');
    if (btn) btn.setAttribute('aria-expanded', 'false');
  });
}
function toggleBreadcrumbDrop(wrapId) {
  var wrap = document.getElementById(wrapId);
  var isOpen = wrap.classList.contains('is-open');
  closeBreadcrumbDrop();
  if (!isOpen) {
    wrap.classList.add('is-open');
    var btn = wrap.querySelector('.ufs-breadcrumb__ellipsis');
    if (btn) btn.setAttribute('aria-expanded', 'true');
  }
}
document.addEventListener('click', function(e) {
  if (!e.target.closest('.ufs-breadcrumb__collapsed')) closeBreadcrumbDrop();
});
ℹ️
toggleBreadcrumbDrop() mirrors the same open/close-on-outside-click pattern already used for the utility bar's language dropdown (toggleLangDrop()) — one open dropdown at a time, closes on any click outside .ufs-breadcrumb__collapsed. aria-expanded is kept in sync on the trigger button for screen readers.
Internationalisation

i18n & RTL

Reading order mirrors automatically under dir="rtl" since the list is a plain flex row with no explicit direction — the browser reverses it for you, same principle as every other flex row in this handover (nav links, carousel head, footer columns). Only two physical properties need an explicit flip: the chevron direction and the dropdown's anchor side.
